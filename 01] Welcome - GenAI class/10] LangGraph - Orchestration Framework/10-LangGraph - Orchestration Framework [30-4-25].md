### Difference between Library & Framework
- What is `Library`?
	- We write sequential flow of code in our way (as some write fun block, if-else, loop..).
	- Some things are imported from LangGraph or Qdrant.
	- That `code flow decide by me as a developer` OR I've also `run Library code`.
	- Where & Which code needs to run for the library? i.e. `Library`.
	- `Library` don't say, which time our code that run (whenver need that code run directly).
- What is `Framework`?
	- We write piece of code, that are run whenever needed i.e. `Framework`.
	- e.g. FastAPI
